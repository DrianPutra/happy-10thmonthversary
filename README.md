# Happy Monthversary Website 💗

Website interaktif bertema rose pink dengan HTML, CSS, dan JavaScript.

## Cara menjalankan
1. Ekstrak folder.
2. Buka `index.html` di browser.
3. Tidak perlu server atau instalasi tambahan.

## File
- `index.html` — struktur website
- `style.css` — desain dan animasi
- `script.js` — interaksi
- `rose-bouquet.png` — gambar bouquet utama

## Bagian yang paling mudah diubah
### Ucapan utama
Cari bagian `.message-card` di `index.html`.

### Teks popup bunga
Ubah nilai `data-message` pada elemen `.flower-card`.

### Nama / sapaan
Ubah teks:
`Happy Monthversary, my love 💗`

### Warna
Ubah variabel warna pada bagian `:root` di `style.css`.
